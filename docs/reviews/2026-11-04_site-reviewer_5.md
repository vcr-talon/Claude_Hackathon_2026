# site-reviewer レビュー（5回目）：4回目の指摘を直した後の見直し

- 依頼：4回目の指摘1〜5の修正と、柱・梁の高さ欄の2段化（「柱・梁の打設済み高さ」／「コン天から ○ mm」。利用者の要望）を見直す
- 条件：5SL～6SL。スクリーンショット 1〜8（7＝タブレット横向き、8＝PCの残量の入力欄）
- 件数：迷う 2件／分かりにくい 2件／好み 1件（4回目の指摘は 1・2・4・5 解消、3 はほぼ解消）
- 対応：利用者の確認待ち。新1「コン天から」は利用者が決めた言い方なので、変えるかは利用者が判断する

## 4回目の指摘
1. 「記録」が3つの意味：解消
2. 長押しで打設中になる説明：解消
3. 見出しのスパン名が図のどこか分からない：ほぼ解消（通り芯の丸印が見えるようになった。近い通り芯の丸印が重なる点は新5）
4. 記録の行が読みづらい：解消
5. 「CSV」と保存先：タブレットは解消。PC画面のボタンに「CSV」が残る

## 新たな指摘
1. 【迷う】「コン天から 280 mm」が、コン天より上か下か分からない。案：「コン天の ［280］ mm 下まで」
2. 【迷う】記録の「打設中　X5〜X6×Y1〜Y2　コン天まで」が打ち終わったように読める。案：「（高さ：コン天まで）」と高さの設定だと分かる書き方に
3. 【分かりにくい】横向きでは説明文が長く、右の欄の先頭に4行、高さの説明も3行。生コン車・割増が画面の下に切れる。案：タップの説明を1行に、細いスパンの注記は「？」で開く形に
4. 【好み】PCの残量の欄に「コン天＝6SL」の説明がない。案：タブレットと同じ一言を添える
5. 【分かりにくい】X6とX7、X10とX11 など近い通り芯の丸印が重なって番号が読めない。案：丸印を上下にずらす

## 内部用語
- PC画面の「残量の一覧表（CSV）を書き出す」「CSVで書き出す」。案：「（Excel用）」
