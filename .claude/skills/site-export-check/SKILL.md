# タブレット用書き出しの確認（site-export-check）

## 手順
1. 実際に画面で書き出して確かめる（アプリを 8767 で起動し、PCのEdgeで「4. 打設終盤の残量」→「タブレット用に書き出す」を押す）
   ```
   .venv\Scripts\python.exe backend\scripts\site_export_check.py 5SL
   ```
   - 書き出したファイルは一時フォルダで確かめて消す（リポジトリにも site_app/ にも残さない）
2. 結果の読み方（1行ずつ「合格／不合格」）
   - 表の先頭が0：全スパンで上端からの表が0から始まる
   - 表が単調増加：深くなるほど体積が減らない
   - スパンの合計＝総数量：`overlap_note` が 0.01 m³ 未満
   - 総数量＝PCの「いまの条件の数量」：画面の小数2桁の値と一致
   - ファイルサイズ：300 KB 以下（メールやチャットで送れる大きさ）
   - タブレットの単体テスト：`node --test` がすべて通る
3. 計算の中身（`backend/qto/site_export.py`）を変えたときは、続けて単体テストも
   ```
   .venv\Scripts\python.exe -m pytest -q backend/tests/test_site_export.py
   ```

## 合格条件
最後の行が「結果：すべて合格」。`overlap_note` 0.01 m³ 未満、300 KB 以下、テスト全通過。

## 失敗したら
- 合計が合わない：スパンの切り方（工区の境界・通り芯）か、スラブ以外からスラブを除く処理を疑う。PCの残量（「4. 打設終盤の残量」で同じスパン・同じ高さ）と比べて、どちらがずれているかを先に確かめる
- 許容値（0.01 m³・300 KB）を合わせに行かない。変えるなら先に利用者に確認を求める
- 書き出したファイルを確認のために残すときも、リポジトリの外（一時フォルダ）に置く
